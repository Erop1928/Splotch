# Splotch

**Drip, press, print.** A physics-based simulator of wax seals: it pours virtual
sealing wax, lets it spread and cool, presses your stamp into it and exports the
result as an STL or a 16-bit heightmap.

![Six wax seals simulated from six stamps](examples/gallery.png)

*Six stamps, six seals. The stamp heightmap is shown in the corner of each tile.*

[Русская версия](README.ru.md)

## Features

- **Pouring.** The wax stream falls from a given height, coils, spreads under its
  own weight and cools. A higher pour gives a wider, more irregular puddle and,
  above ~80 mm, splashes.
- **Pressing.** The stamp comes down with an offset, rotation and tilt. Displaced
  wax flows into the stamp's cavities and out past its edge, forming a rim. The
  stamp stops where its force balances the resistance of the cooling wax.
- **Timing matters.** Press too late and the wax has set, giving a shallow or
  incomplete impression. Too little wax and the edges of the design are cut off.
- **Randomization.** Every simulation parameter accepts a fixed value, a range or
  a normal distribution, so a batch of seals never looks the same.
- **Exports.** Watertight binary STL, 16-bit PNG heightmap with a JSON sidecar
  (mm per pixel, mm at white), raw `.npy`, and a shaded preview.

## Install

```bash
pip install -r requirements.txt   # numpy, scipy, pillow
```

Python 3.9 or newer.

## Quick start

```bash
# make a demo stamp to play with
python3 splotch.py --make-demo-stamp stamp.png

# one seal
python3 splotch.py --stamp stamp.png --stamp-size 25 --out seal

# ten random seals
python3 splotch.py --stamp stamp.png --stamp-size 25 --relief-depth 1.2 \
    --volume 1.5 --drop-height 30:80 --force 40~10 \
    --offset-x -1:1 --offset-y -1:1 --rotation 0~3 --tilt 0:2 \
    --count 10 --seed 1 --out seals/seal
```

Ready-made stamps (circle, star, diamond, hexagon, heart, shield) are in
[`examples/stamps/`](examples/stamps), generated by
[`examples/make_stamps.py`](examples/make_stamps.py):

```bash
python3 splotch.py --stamp examples/stamps/star.png --stamp-size 26 --volume 2 --out star
```

A seal takes about 30 s at the default 0.15 mm grid. Use `--resolution 0.25`
for quick drafts (~7 s).

## Stamp heightmap

The stamp is a grayscale image (8 or 16 bit, PNG/JPG/TIFF) that describes both
the relief **and the shape of the stamp itself**:

| Pixel | Meaning |
|---|---|
| Brightness | How far the stamp material protrudes toward the wax |
| "Empty" color (black by default, `--empty white` to flip) or transparency | No material at all; this defines the stamp outline |
| Empty areas enclosed by the outline | Deepest recess of the relief (`--holes-through` makes them through-holes) |

Physical size: `--stamp-size` is the image width in mm, `--relief-depth` is the
height range from "empty" to full white in mm.

The image is treated as a view **of the stamp face**, so the impression is
mirrored. If your image already shows the finished seal (text reads correctly),
add `--no-mirror`.

Example: in [`examples/stamps/circle.png`](examples/stamps/circle.png) the
black background is empty, the gray disc is the stamp face, the white rim, dots
and laurel leaves protrude (they become grooves in the wax), and the dark "S" is
recessed (it comes out raised). The "S" is drawn mirrored, as on a real stamp,
and reads correctly on the seal.

![One stamp under four pouring and pressing conditions](examples/conditions.png)

| Seal | What changed |
|---|---|
| classic | defaults, 1.6 cm³ |
| high pour, offset, tilt | 2 cm³ poured from 180 mm, 60 N, stamp off by (2, −1.5) mm and tilted 2° |
| pressed too late | 12 s pause before pressing: the wax has set, the impression is shallow |
| little wax, weak press | 1.1 cm³ and 12 N: the design is faint and the edges barely form |

All parameters of every example are saved next to it in a `.json` file in
[`examples/gallery/`](examples/gallery) and [`examples/conditions/`](examples/conditions).

## Parameters

Every simulation parameter takes one of:

| Syntax | Meaning |
|---|---|
| `40` | fixed value |
| `30:50` | uniform random in the range |
| `40~5` | normal distribution, mean~sigma |

Negative ranges work as is: `--offset-x -2:2`.

| Option | Default | Meaning |
|---|---|---|
| `--volume` | 1.5 | wax volume, cm³ |
| `--drop-height` | 40 | pour height, mm |
| `--pour-rate` | 400 | pour rate, mm³/s |
| `--pour-wobble` | 0.8 | hand shake while pouring, mm |
| `--stream-radius` | 1.5 | wax stream radius, mm |
| `--temp` / `--ambient` | 115 / 22 | wax and paper temperature, °C |
| `--delay` | 4 | pause between pouring and pressing, s |
| `--force` | 40 | press force, N |
| `--offset-x` / `--offset-y` | 0 | stamp offset from the puddle center, mm |
| `--rotation` | 0 | stamp rotation, degrees |
| `--tilt` / `--tilt-dir` | 0 / 0:360 | stamp tilt and its direction, degrees |
| `--press-speed` | 4 | stamp descent speed, mm/s |
| `--dwell` | 5 | time the stamp is held down, s |

Material constants (`--viscosity`, `--visc-slope`, `--yield-stress`,
`--yield-slope`, `--cool-time`, `--stamp-chill`) and numerics (`--resolution`,
`--canvas`, `--press-step`, ...) are listed in `python3 splotch.py --help`.

## Output

For each seal, `<prefix>`:

| File | Content |
|---|---|
| `<prefix>.stl` | watertight solid of the wax; `--stl-base` adds a base plate, `--stl-step` thins the mesh |
| `<prefix>_height.png` | 16-bit heightmap; height in mm = value / 65535 × `z_mm_at_white` |
| `<prefix>.json` | sampled parameters, press result, heightmap scale |
| `<prefix>_preview.png` | shaded preview |
| `<prefix>_height.npy` | float heights in mm (with `--format npy`) |

Pick formats with `--format stl,png,npy`. Use `--hm-zmax` to give every seal in a
batch the same heightmap scale.

## How it works

1. **Pour.** Wax is deposited along a coiling, wobbling stream path. Spreading
   follows the thin-film equation `h_t = ∇·(ρg h³ / 3μ ∇h)`. Viscosity grows
   exponentially as the wax cools, and thin edges freeze first. Pouring runs on a
   coarser grid for speed.
2. **Press.** At each descent step, wax above the stamp surface is pushed out
   by a pressure field solved over the contact zone (`∇·(K∇p) = source`,
   `K ∝ h³`, `p = 0` wherever there is free space). The stamp's resistance uses
   Prandtl's squeeze formula for a plastic layer, `p ≈ σ_y(T)·(1 + R / 3h)`.
3. **Dwell and lift.** Wax under the cold stamp cools faster. After lifting it
   relaxes briefly.

## Limitations

- 2.5D model: no overhangs, air bubbles, or wax strings from lifting the stamp
  too early.
- Material constants are tuned by eye for plausible results, not measured. If
  impressions come out too shallow or too deep for your force, adjust
  `--yield-stress` first.
- The command-line help is in Russian.
